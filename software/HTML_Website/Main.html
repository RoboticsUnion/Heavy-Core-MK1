Community Guidelines

Content Creation

Content creation is allowed within this project, but strictly limited to the graphical user interface (GUI). The GUI layer may be modified, redesigned, extended, and visually improved as needed.

Supported Libraries

The GUI can be developed using:

import os
import PySide6.QtWidgets as qw
import PySide6.QtCore as qc
import PySide6.QtGui as qg

Security Notice

The following safety elements MUST be included:

  • Digital emergency stop
  • Temperature monitoring (motors & voltage)
  • Load / utilization display
  • Power consumption display
  • Overload protection indicator
  • Motor status overview
  • Cooling system control

By contributing, you agree to follow these guidelines.
